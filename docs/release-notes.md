Paperdesk 0.1.4 adds a compact quick-reference card.

Right-click a note and choose Quick reference, or press F1 while writing. The card appears beside the note and lists eight everyday actions in two columns. It has no title bar, introductory text, section headings, or standard dialog buttons. Drag its header to move it, and close it with Escape or the close icon.

The card can stay open while you work. Opening it while editing preserves the draft; closing it returns focus to the editor. F1 is local to Paperdesk and does not register a system-wide shortcut.

Paperdesk.exe --help and the existing Paperdesk help launcher shortcut open the same card. Full launcher commands remain in the README.

Install or update with ./scripts/install.ps1 from the release ZIP. Saved notes remain compatible with previous 0.1.x releases from 0.1.1 onward. The executable is an unsigned preview, with a SHA-256 checksum provided alongside the download.
